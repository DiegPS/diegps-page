# diegps-page

Portfolio and product pages for Diego Pahua Silvan, AirDown, AirStream Studio, and DevScope Concept.

## Routes

- `/` — Portfolio
- `/airdown` — AirDown product page
- `/airdown/privacy` — AirDown privacy policy
- `/airstream` — AirStream Studio product page
- `/airstream/privacy` — AirStream Studio privacy policy

## Development

```bash
npm install
npm run dev
```
